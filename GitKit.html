This builds a suggested command; it doesn't run anything. Use it as a starting point and edit before running. Commands that rewrite history (rebase, reset --hard, force push, clean) can lose work, so the page warns you and the preview options are on by default where it helps. Less common options (worktrees, bisect, submodule, sparse-checkout details, hooks) are left out; see git help.
